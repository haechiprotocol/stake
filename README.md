# 6. Staking Smart Contract Mechanics
Staking opens after Node Presale concludes. The contract distinguishes between tokens staked via Node claims (stakedFromNode) and regular wallet deposits (stakedFromWallet):

Staking Parameter	Smart Contract Execution Rules:
1. Daily Reward Rate	0.83% per Day (Calculated per second in real-time, configurable by Owner)
2. Locked USD Valuation	Base price of $0.10 USD / Token (Locked historically at the exact time of staking to preserve qualification ranks regardless of future token price volatility)
3. Max Payout Cap (300%)	Maximum claimable reward is 300% of Active Principal. Once Staking ROI + Network Bonuses reach 300%, staking deactivates automatically and users can Restake.
4. Top-Up Mechanism	Wallets can add stake anytime; max cap adapts dynamically to 300% of total active principal.
5. Early Unstake (40% Penalty)	Unstaking before reaching 300% incurs a 40% penalty on principal, returning 60% of principal (excluding previously claimed rewards).

# 8. Gas Fee Optimization & Multi-Layer Security
